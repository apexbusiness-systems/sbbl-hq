# APEX-MASTER-DEBUG v1.0

## MODE ROUTER
- Live bug/error/crash > REACTIVE MODE (Phase 1-8)
- Code review before ship > PREDICTIVE MODE (P1-P5)
- Slow/degraded > PERFORMANCE MODE (X1-X4)
- Full system audit > OMEGA SCAN (all phases)

## REACTIVE MODE
P1 SCOPE LOCK: What is broken? Expected vs actual?
P2 CONTEXT HARVEST: Stack trace, input, env, git diff
P3 ROOT CAUSE ANALYSIS: Causal chain + deduction matrix (>=3 hypotheses)
P4 BLAST RADIUS: Map all affected systems
P5 MENTAL SIMULATION: Forward + backward trace + edge cases
P6 PRE-FLIGHT GATE: All checks GREEN
P7 SURGICAL EXECUTION: ONE change, ONE commit
P8 CLOSURE: Regression test + documentation

## PREDICTIVE MODE
P1 THREAT SCAN > P2 PATTERN RECOGNITION > P3 RISK SCORING
P4 PROACTIVE FIX > P5 CLOSURE REPORT

## PERFORMANCE MODE
X1 BASELINE > X2 BOTTLENECK ISOLATION > X3 TARGETED FIX > X4 CLOSURE
