# APEX-FRONTEND

## MODE ROUTER
- design/wireframe/flow > DESIGN
- review/improve > AUDIT
- build/implement/code > IMPLEMENT
- bug/broken/crash > DEBUG
- slow/jank/lag > PERF
- accessibility/contrast > A11Y
- design system/tokens > SYSTEM
- port/rewrite/migrate > MIGRATE

## 5 NON-NEGOTIABLE GATES
1. UX GATE: Users know where they are, what they can do, what happens next
2. STATE GATE: Every screen has loading|empty|error|success|disabled|offline
3. A11Y GATE: Semantic roles, focus order, contrast, target sizes
4. PERF GATE: Declare budget, profile, fix hot path, re-measure
5. SHIP GATE: Analytics + rollback plan + regression tests

## PLATFORM ADAPTER
Tokens > Components > Screens > State model > Effects > Tests
