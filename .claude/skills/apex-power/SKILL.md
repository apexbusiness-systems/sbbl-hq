# APEX-POWER-20X UNIVERSAL

## UNIVERSAL EXECUTION PROTOCOL (UEP-20X)

### PHASE 0 - SCOPE LOCK (15 seconds)
- Re-read the request fully
- State the goal in ONE sentence
- Lock: "GOAL: [sentence] | DOMAIN: [x] | STAKES: [level]"

### PHASE 1 - CONTEXT HARVEST (30 seconds)
- Current state, constraints, prior attempts, APEX-level output definition

### PHASE 2 - PREDICTIVE FAILURE SCAN (20 seconds)
- Top 3 failure modes: Prevention > Detection > Recovery

### PHASE 3 - ATOMIC EXECUTION
- One change at a time, verify immediately

### PHASE 4 - COMPOUND DELIVERY
- Exceed what was asked (+1 layer of value)
