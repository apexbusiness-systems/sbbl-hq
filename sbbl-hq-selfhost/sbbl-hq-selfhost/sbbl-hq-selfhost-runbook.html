01 Stack Architecture @ sbbl-hq.icu

🔒
Caddy terminates TLS and auto-renews Let's Encrypt certificates. All internal traffic flows over HTTP inside the Docker network. No self-signed certs needed.

  • Export enabled providers (email, magic link, Google, GitHub, Apple)
  • Export password policy — minimum length, complexity, HIBP toggle
  • Export CAPTCHA settings (Turnstile site key + secret)

05 Pre-Launch Checklist

Infrastructure

  • Server: 8 vCPU / 32 GB RAM minimum for 50K users
  • DNS A record sbbl-hq.icu → server IP
  • Ports 80 + 443 open (firewall + cloud security group)
  • Caddy TLS cert issued (Let's Encrypt)
  • Automated daily backups configured
  • Monitoring / alerting on Postgres CPU + disk

Auth Security

  • JWT_SECRET ≥ 56 chars, securely generated
  • ANON_KEY + SERVICE_ROLE_KEY regenerated (not Supabase Cloud keys)
  • HIBP leaked password protection ON
  • Turnstile CAPTCHA ON for signup + login
  • Refresh token rotation ON
  • Rate limits configured (signup: 10/hr, email: 100/hr)

App Integration

  • SUPABASE_URL updated to https://sbbl-hq.icu in all Workers secrets
  • ANON_KEY updated in Cloudflare Pages env
  • SERVICE_ROLE_KEY updated in Workers (server-side only)
  • OAuth callback URLs updated in Google / GitHub consoles
  • Turnstile widget still uses same site key (no change needed)

Load Validation

  • k6 load test: 5 000 VU peak sustained 3 min
  • p95 auth latency < 600ms
  • Error rate < 1%
  • Postgres connections ≤ 80% pool capacity
  • Realtime WebSocket connections stable
