## Iron Core

2. **EXECUTE** once, surgically (zero iteration)

## Zero-Iteration Debug (7 Phases)

| Phase | Name | Key Gate |
|-------|------|----------|
| P1 | SCOPE LOCK | Define EXACT symptom in ONE sentence |
| P2 | EVIDENCE HARVEST | Full stack trace, input, env, code, git diff |
| P3 | ROOT CAUSE DEDUCE | Prove ONE cause, eliminate ALL others |
| P4 | MENTAL SIMULATION | Forward + backward trace + edge cases + blast radius |
| P5 | PRE-FLIGHT GATE | All must be GREEN |
| P6 | SURGICAL EXECUTE | ONE precise change |
| P7 | CLOSURE | Regression test + root cause documented |

| Users | Team Size | Recommendation |
|-------|-----------|---------------|
| <1K | 1-3 | Monolith + PostgreSQL |
| 1K-100K | 4-10 | Modular monolith |
| 100K-1M | >10 | Microservices + cache + CDN |

## Security Fortress (OWASP-Aligned)

| Layer | Key Requirements |
|-------|-----------------|
| Auth | OAuth2/OIDC, JWT <15min, bcrypt >= 12, MFA |
| Input | Validate ALL, parameterized queries, escape output, CSRF |
| Transport | TLS 1.3, HSTS, cert pinning for mobile |
| Secrets | Env vars / secrets manager only, rotate |
| Access | RBAC, deny by default, least privilege |
| Deps | Pin versions, auto-scan, Dependabot/Renovate |

## IP Moat Layers

1. Proprietary algorithms (custom logic solving unique problems)
2. Data network effects (more users = better product)
3. Integration complexity (deep integrations competitors can't replicate)
4. Switching costs (workflow embedding)
5. Trade secret protection (obfuscation, access control, NDA gates)
