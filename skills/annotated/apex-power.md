## Core Protocol: APEX-UEP (Universal Execution Protocol)

| Phase | Name | Purpose | Time |
|-------|------|---------|------|
| 0 | SCOPE LOCK | Read request 3x, state goal in ONE sentence | 30 sec |
| 1 | CONTEXT HARVEST | Identify files, state, constraints, prior attempts | Before action |
| 2 | PLAN | Define steps, risks, verification criteria | Before implementation |
| 3 | EXECUTE | Test first, minimal change, verify, commit atomically | One thing at a time |
| 4 | VERIFY | Run it, test it, match goal, prove it | Before claiming done |
