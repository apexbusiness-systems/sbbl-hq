## 2024-05-19 - Ops Page Redundant Filter Deduplication
**Learning:** In `src/pages/Ops.tsx`, the inline rendering of multiple UI segments relying on the exact same array `.filter()` operation on every render causes redundant O(N) evaluations, especially noticeable for larger collections like the offline queue.
**Action:** When mapping over filtered arrays and conditionally rendering elements based on their length within JSX, extract the `.filter()` operation into a `useMemo` hook to compute it exactly once per dependency change, eliminating repetitive CPU overhead while preserving referential equality.
